ПЕПЕЛЬНЫЙ ПУТЬ — релизный пакет 1.1.1 «Живая Бездна»
======================================

Файлы:
  index.html     — вся игра (один файл, работает офлайн)
  manifest.json  — описание приложения (установка на телефон, «На главный экран»)
  sw.js          — Service Worker: после первого запуска игра открывается без интернета
  icon-192.png, icon-512.png — иконки приложения
  avatar-1024.png        — аватар бота/канала в Telegram (круглая обрезка безопасна)
  banner-640x360.png     — обложка Mini App (BotFather просит 640×360)
  logo.png, logo_transparent.png — логотип для постов, itch.io, Reddit

Как выложить:
  1. Загрузи ВСЕ файлы в одну папку на хостинге с HTTPS
     (GitHub Pages, Cloudflare Pages, Netlify, твой сервер).
  2. Открой https://<твой-адрес>/index.html — игра сама подключит manifest и sw.js.
  3. На телефоне: меню браузера → «Добавить на главный экран».

Telegram Mini App:
  1. @BotFather → /mybots → бот → Bot Settings → Menu Button (или /newapp)
  2. Укажи адрес https://<твой-адрес>/index.html
  3. Фото бота: /setuserpic → avatar-1024.png; обложка приложения: banner-640x360.png
  Внутри Telegram игра сама подключит Telegram WebApp, развернётся на весь экран
  и будет копировать сейв в облако Telegram каждые 5 минут
  (Меню → Настройки → Облако Telegram).

Обновление:
  Просто замени index.html. Service Worker берёт свежую версию при наличии сети,
  а без сети — из кэша. Сейвы игроков сохраняются (версионирование и миграции встроены).

Сохранения игрока:
  localStorage + IndexedDB + 3 автоматические резервные копии (раз в 10 минут),
  экспорт/импорт кодом и «Сообщить о проблеме» в Меню → Настройки.
